## Selected projects

- **[Water Meter OCR](https://github.com/Bortrex/water-meter-ocr)** — Ongoing JAX/Flax reimplementation of a TensorFlow OCR proof of concept for reading analog water meters from photographs. The current implementation covers U-Net display segmentation, with training and validation results; sequence recognition remains to be implemented.

- **[Gradient-Free Reinforcement Learning](https://github.com/Bortrex/lunarlander-gradient-free-rl)** — Compares population-based optimization, zeroth-order SGD and Adam, and Augmented Random Search on continuous LunarLander. Uses PyTorch and JAX, with repeated experiments and parallel policy evaluation.

- **[Audio Digit Recognition](https://github.com/Bortrex/audio_digit_recognition)** — Classifies spoken digits using MFCC audio features and a PyTorch convolutional network. Includes preprocessing, training and validation, and inference from WAV files or microphone recordings.

- **[Discrete Optimization](https://github.com/Bortrex/DO_project)** — Assigns students to exam series using an integer programming model and a simulated annealing heuristic in Julia. Compares solution quality and runtime, with a written technical report.

- **[Consumer Adoption Analytics](https://github.com/Bortrex/consumer-adoption-powerbi)** — Ongoing Power BI project exploring survey data on drivers and barriers to consumer adoption. The data model and report are under development as part of my expanding analytics practice.
